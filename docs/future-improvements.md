# 후속 개선사항

## 종목 검색 속도 및 입력 UX

2026-10-06 사용자 요청으로 이번 필수 기능·배포 작업에서 제외하고 후속 개선으로 보류합니다.

- 서버 메모리에 종목 목록을 재사용하여 검색마다 Firestore 전체 목록을 다시 읽는 비용과 지연을 줄입니다.
- 입력 후 약 300ms에 자동 검색하는 디바운스를 적용합니다.
- 검색 중 표시와 이전 요청 취소/늦은 응답 무시를 적용합니다.
- 종목 목록 잠금과 가격 갱신 잠금의 경합을 점검합니다.
- 변경 전후 실제 응답 시간을 측정하고 비교합니다.

현재는 검색 버튼 또는 Enter로 실행되며, 부분 일치 결과를 30개씩 반환합니다. 이번 보류 결정으로 기존 동작은 변경하지 않습니다.
